# commercialistaonline

Studio di commercialista online per professionisti, partite IVA e piccole aziende. Solo elenco dei siti da fare, nessun sito costruito.

## Siti che faremo
1. **Sito dello studio**: home, servizi (contabilita', dichiarazioni, apertura partita IVA, buste paga), pacchetti e prezzi, contatti e preventivo.
2. **Guide fiscali**: blog con guide per partita IVA, regime forfettario, scadenze, detrazioni, costituzione societa'.
3. **Calcolatori**: forfettario, imposte, netto/lordo, scadenzario (strumenti web semplici).
4. **Area clienti**: invio documenti e scadenze (da valutare sicurezza e privacy).

## Note
- Il sito deve essere intestato a un commercialista iscritto all'albo: i servizi professionali li fornisce lui, noi facciamo la parte web.
- Informazioni fiscali sempre verificate e datate; testi originali.
- Si collega a `cyberpmi` (sicurezza e GDPR per le PMI).
